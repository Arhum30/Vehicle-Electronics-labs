# Crash Impact Sound Sensing (CISS) Analysis

This project documents a laboratory investigation of Crash Impact Sound Sensing (CISS) using a crash beam, accelerometers, and frequency-domain analysis.

## Overview

The goal of this lab was to study how structure-borne sound propagates through a metallic vehicle component and how this principle can be used for fast crash detection in automotive safety systems.

The experiment focused on:
- Time-domain signal analysis
- Impact position comparison
- Impact force comparison
- FFT-based frequency-domain analysis
- Interpretation of structural resonance behavior

## Tools and Technologies

- MATLAB
- FFT analysis
- Time-domain signal analysis
- LTT24 data acquisition system
- LTTpro
- Modal hammer testing
- Kistler accelerometers

## Experimental Setup

The setup included:
- Crash beam as the structural test object
- Modal hammer for controlled excitation
- Two accelerometers mounted at different beam positions
- Signal acquisition and post-processing in MATLAB

## What was done

- Recorded hammer and accelerometer signals for different hit positions
- Compared sensor responses for light and strong impact forces
- Evaluated propagation timing and ring-down behavior
- Converted selected measurements into the frequency domain using FFT
- Identified characteristic resonant frequency regions of the crash beam

## Key Findings

- Structure-borne sound reached both sensor locations within milliseconds
- Signal amplitudes scaled with impact force, indicating approximately linear system behavior
- Hit position influenced relative sensor response and mode excitation
- FFT analysis revealed characteristic structural resonance peaks
- The experiment demonstrated why CISS can support faster crash detection than conventional methods

- Real-world engineering use of resonance signatures
