# Automotive Systems Labs

A collection of automotive engineering lab projects completed at Technische Hochschule Ingolstadt, covering vehicle electronics, communication networks, sensors, actuators, control systems, simulation, and vehicle dynamics.

## Overview

This repository contains practical lab work focused on automotive systems engineering. The projects combine simulation, measurement, embedded control, signal analysis, and ECU/network validation using industry-relevant tools and engineering workflows.

The labs included in this repository cover:
- Adaptive Cruise Control (ACC) sensor evaluation
- Crash Impact Sound Sensing (CISS)
- Hardware-in-the-Loop (HiL) ECU validation
- Ultrasonic sensor and linear actuator control
- Steady-circle vehicle dynamics analysis
