# Steady Circle Vehicle Dynamics Analysis

This project documents a vehicle dynamics lab based on steady-state cornering simulations in CarMaker and post-processing in MATLAB.

## Overview

The objective of this lab was to investigate how different vehicle parameters influence lateral dynamics during a steady-circle maneuver.

The study focused on the effect of:
- center of gravity position,
- stabilizer stiffness,
- and tire characteristics

on steering behavior and vehicle response.

## Tools and Technologies

- CarMaker
- IPG Control
- MATLAB
- Vehicle dynamics analysis
- Yaw gain evaluation
- Steering angle analysis

## What was done

- Simulated steady-circle maneuvers in CarMaker
- Compared multiple vehicle parameter variations
- Processed simulation output files in MATLAB
- Evaluated yaw gain vs. speed
- Evaluated steering angle vs. lateral acceleration
- Classified vehicle behavior as understeering, near-neutral, or oversteering
- Interpreted characteristic and critical speed trends

## Key Findings

- Shifting center of gravity changed the steering character significantly
- Stabilizer stiffness distribution strongly influenced understeer/oversteer behavior
- Tire changes affected the intensity of understeer, but did not reverse the steering character
- Load distribution had a stronger effect on steering behavior than absolute tire grip
- The steady-circle test proved useful for reproducible vehicle dynamics evaluation

## Learning Outcomes

This lab strengthened practical understanding of:
- steady-state cornering analysis
- understeer and oversteer classification
- yaw gain interpretation
- parameter sensitivity in vehicle dynamics
- CarMaker-to-MATLAB post-processing workflows
